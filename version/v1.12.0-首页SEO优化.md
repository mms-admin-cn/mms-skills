# v1.12.0 首页 SEO 优化

## 变更类型
优化

## 变更范围
`index.html` — 标题、关键词、描述、OG 标签

## 背景
当前首页 meta 标签存在标题过长、描述信息密度低、关键词冗余等问题，不利于搜索引擎抓取和搜索结果展示。

## 变更内容

### Title
- 旧：`MMS AI 技能库 — 面向 Cursor / Codex / Claude Code 的共享技能中心`
- 新：`MMS AI 技能库 | Cursor · Codex · Claude Code 共享技能中心`
- 理由：压缩长度，用 `|` 和 `·` 替代冗长的「面向」「的」，保持核心关键词完整。

### Keywords
- 旧：`MMS,AI技能库,技能库,共享技能,Cursor,Codex,Claude Code,uni-app,HBuilderX,插件开发,前端设计,多智能体,API测试,部署运维`
- 新：`MMS,AI技能库,共享技能,Cursor,Codex,Claude Code,智能体,uni-app,JAR插件,多智能体协作`
- 理由：移除与标题重复的泛词（技能库），精简长尾词，聚焦搜录价值更高的词组。

### Description
- 旧：以「MMS AI 技能库是一套…」开头（与标题重复）
- 新：以差异化价值点开头，控制在 140 字符内

### OG 标签
- og:title 与 title 同步更新
- og:description 保持比 meta description 更精简的版本
- 补充 og:image（如有 Logo）

## 验收标准
- [ ] 页面 title 在搜索结果中完整显示，不被截断
- [ ] description 在搜索结果中信息密度高，无冗余
- [ ] OG 标签在微信/QQ/Twitter 分享时正确展示
