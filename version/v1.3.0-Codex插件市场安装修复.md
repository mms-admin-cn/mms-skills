# v1.3.0-Codex插件市场安装修复

## 背景与目标

当前本机 Codex 已启用 `openai-bundled` 插件市场，`Browser`、`Chrome`、`Computer Use`、`LaTeX` 等内置插件可用；但官方扩展插件市场 `openai-curated` 只存在于 `~/.codex/.tmp/plugins/` 临时目录，且 `openai-curated` 是 Codex 保留 marketplace 名称，不能从本地路径或 `openai/plugins` 普通源手动注册。首次尝试注册自定义 `codex-all-plugins` marketplace 后，CLI 配置成功但桌面插件页不展示该自定义市场，因此需要改用 Codex 默认可发现的个人市场入口。

目标是把本机已缓存的 Codex 官方扩展插件复制到默认个人插件目录 `~/plugins/`，并生成 `~/.agents/plugins/marketplace.json` 个人市场清单，让桌面插件页能发现 `personal` 市场中的插件安装入口。

## 需求范围

### 本次包含

- 检查本机 Codex marketplace 与插件策略配置。
- 创建默认个人插件目录 `~/plugins/`。
- 生成默认个人市场文件 `~/.agents/plugins/marketplace.json`。
- 验证 `personal` 插件条目均为 `AVAILABLE`。
- 通过临时 app-server 的 `plugin/list` 验证新进程可发现 `personal` 市场。
- 复盘并沉淀一条 Codex 插件市场排障经验到共享技能库。

### 本次不包含

- 不修改官方插件源码或缓存内的 `.codex-plugin/plugin.json`。
- 不自动登录、授权或安装需要第三方账号认证的插件。
- 不删除或重置用户已有 Codex 配置。
- 不改动 `openai-bundled` 内置插件市场。

## 实施步骤

1. 检查 `~/.codex/config.toml` 中已注册的 marketplace。
2. 检查 `~/.codex/.tmp/plugins/.agents/plugins/marketplace.json` 中插件安装策略。
3. 尝试直接注册 `openai-curated`，确认 Codex CLI 因保留名拒绝。
4. 尝试自定义 `codex-all-plugins` marketplace，确认 CLI 接受但桌面 UI 不展示该自定义市场。
5. 移除无效的 `codex-all-plugins` marketplace 配置。
6. 将 `~/.codex/.tmp/plugins/plugins/` 复制到 `~/plugins/`。
7. 生成 `~/.agents/plugins/marketplace.json`，顶层 `name = personal`，插件条目策略不变。
8. 验证插件策略均为 `AVAILABLE`，且每个 marketplace 条目都能解析到 `~/plugins/<plugin>/.codex-plugin/plugin.json`。
9. 通过临时 `codex app-server --listen stdio://` 调用 `plugin/list`，确认可返回 `personal` 市场。
10. 将可复用经验沉淀到 `skills-shared/`。

## 风险与回滚

- 风险：`~/.codex/.tmp/plugins` 属于 Codex 临时缓存，未来若被清理，marketplace 源路径可能失效。
  - 处理：不直接注册临时目录，改为复制插件目录到 `~/plugins/`，用 `~/.agents/plugins/marketplace.json` 默认个人市场暴露。
- 风险：个人市场镜像不会自动跟随官方 `openai/plugins` 更新。
  - 处理：后续需要更新时重新同步缓存或从官方仓库更新镜像，再执行 marketplace 注册/升级校验。
- 风险：运行中的桌面 App 不会立即读取新建个人市场。
  - 处理：完整退出 Codex 后重新打开；独立新启动 app-server 已验证可发现 `personal` 市场。
- 风险：部分插件虽可安装，但仍需要第三方账号授权。
  - 处理：本次只保证安装入口可用，不绕过插件自身的认证流程。
- 回滚：删除 `~/.agents/plugins/marketplace.json`，并按需删除本次复制的 `~/plugins/` 官方插件目录；`codex-all-plugins` 自定义 marketplace 配置已移除。

## 验收标准

- `~/.agents/plugins/marketplace.json` 存在，顶层 `name` 为 `personal`。
- `personal` marketplace 的 171 个插件条目统计为 `AVAILABLE`。
- marketplace 中每个插件条目都能找到对应 `.codex-plugin/plugin.json`。
- 新启动 app-server 的 `plugin/list` 能返回 `personal` marketplace。
- 现有 `openai-bundled` 插件仍保持启用。
- 共享技能库记录 Codex marketplace 注册与排障方法。

## 验证结果

- 已生成 `~/.agents/plugins/marketplace.json`，顶层 `name` 为 `personal`。
- 已验证个人市场包含 171 个插件，`policy.installation` 全部为 `AVAILABLE`。
- 已验证 171 个插件条目均能解析到 `~/plugins/<plugin>/.codex-plugin/plugin.json`，缺失数为 0。
- 已通过新启动的 `codex app-server --listen stdio://` 调用 `plugin/list`，返回结果包含 `personal` marketplace 与 `linear@personal` 等插件 ID。
- 验证过程中出现远程精选插件同步 401，这是未登录 ChatGPT 远程同步导致，不影响本地 `personal` 市场发现。

## 复盘沉淀

- 有效做法：不要把 `openai-curated` 当普通本地 marketplace 注册；它是 Codex 保留名，会被 CLI 拒绝。
- 有效做法：桌面端展示本机插件时，默认个人市场 `~/.agents/plugins/marketplace.json` 比自定义本地 marketplace 更稳定。
- 踩坑记录：自定义 marketplace 可以被 CLI 写入 `~/.codex/config.toml`，但桌面插件页可能不展示，不能只以 CLI 注册成功作为验收。
- 可复用经验已沉淀到 `skills-shared/codex-plugin-marketplace/SKILL.md`，并在 `skills-shared/README.md` 增加触发索引。
