# v1.4.0-UniAppX技能清理与uniapp技能重整

## 背景与目标

当前共享技能库中存在多组围绕 `mms-unix`、Uni-App X、UTS、UVue、UCSS 的技能。后续不再维护 Uni-App X 项目，因此这些技能继续留在触发索引中会让 Agent 在普通 uni-app 或 Vue/H5 工作中误入旧项目语境。

目标是清理 Uni-App X 与 `mms-unix` 专用技能，同时保留 HBuilderX 自动化能力，并将其重整为普通 uni-app 项目的编译、运行、日志与验证技能。

## 需求范围

### 本次包含

- 删除 `skills-shared/` 下 Uni-App X 与 `mms-unix` 专用技能目录。
- 保留 `hbuilderx-automation`，但改造为普通 uni-app / HBuilderX 自动化技能。
- 清理 `skills-shared/README.md` 中的 `mms-unix` 调用关联。
- 清理其他技能中指向已删除 Uni-App X / `mms-unix` 技能的交叉引用。
- 同步处理本机 `~/.codex/skills` 中已经安装的旧技能副本，避免后续会话继续触发。
- 保留历史 `version/` 文档，作为仓库演进记录，不作为技能触发入口。

### 本次不包含

- 不删除 HBuilderX 自动化能力。
- 不删除普通 uni-app、Vue、H5、Tauri 桌面相关技能。
- 不改业务项目源码。

## 实施步骤

1. 扫描 `skills-shared/` 中 `mms-unix`、Uni-App X、UTS、UVue、UCSS、HBuilderX 相关技能与引用。
2. 创建本版本文档，记录清理边界。
3. 重写 `skills-shared/hbuilderx-automation/SKILL.md`，移除 Uni-App X 专用判断，改为普通 uni-app/HBuilderX 工作流。
4. 删除 Uni-App X 与 `mms-unix` 专用技能目录。
5. 更新 `skills-shared/README.md`、`mms-desktop`、`mms-doc-authoring` 中的旧引用。
6. 将本机 `~/.codex/skills/mms-unix-doc`、`~/.codex/skills/uni-app-x-ucss` 移入备份目录，并同步更新 `~/.codex/skills/hbuilderx-automation/SKILL.md`。
7. 复查 `skills-shared/` 内是否仍有会触发 Uni-App X 项目的关键词残留。

## 风险与回滚

- 风险：删除技能后，历史 `mms-unix` 文档或 Uni-App X 项目无法再被技能自动命中。
  - 处理：这是本次目标；历史文档仍保留在 `version/` 中，可按需人工追溯。
- 风险：普通 uni-app 与 Uni-App X 术语相近，HBuilderX 技能可能误触发旧语境。
  - 处理：在 `hbuilderx-automation` 描述和正文中明确排除 Uni-App X / UTS / UVue / UCSS。
- 回滚：恢复被删除的 `skills-shared/mms-unix-*`、`skills-shared/uni-app-x-ucss` 目录，并恢复 README 与交叉引用。
- 本机安装副本回滚：从 `~/.codex/skills-archive/2026-06-04-uniappx-cleanup/` 移回对应目录。

## 验收标准

- `skills-shared/hbuilderx-automation/SKILL.md` 保留，并以普通 uni-app/HBuilderX 为触发语义。
- `skills-shared/README.md` 不再包含 `mms-unix` 调用关联。
- `skills-shared/` 中不再存在 `mms-unix-*` 或 `uni-app-x-ucss` 技能目录。
- 除历史 `version/` 文档外，技能正文中不再保留 Uni-App X / UTS / UVue / UCSS 触发引用。

## 验证结果

- `rg` 扫描确认 `skills-shared/` 中已无 `mms-unix`、Uni-App X、UTS、UVue、UCSS 命中。
- `find skills-shared -maxdepth 1 -type d` 确认仅保留 `skills-shared/hbuilderx-automation`，不再存在 `mms-unix-*` 或 `uni-app-x-ucss` 目录。
- `~/.codex/skills/mms-unix-doc` 与 `~/.codex/skills/uni-app-x-ucss` 已移入 `~/.codex/skills-archive/2026-06-04-uniappx-cleanup/`。
- `~/.codex/skills/hbuilderx-automation/SKILL.md` 已同步为普通 uni-app/HBuilderX 版本。

## 复盘沉淀

- 清理技能不能只改共享仓库；若当前 Codex 已安装旧技能，必须同步处理 `~/.codex/skills`，否则后续会话仍可能从安装副本触发。
- HBuilderX 与 Uni-App X 不应绑定：HBuilderX 是工具能力，普通 uni-app 仍需要；真正需要移除的是 Uni-App X、UTS、UVue、UCSS 与 `mms-unix` 专用规则。
- 历史 `version/` 文档保留为演进记录，不参与技能触发；验证残留时要区分 `skills-shared/` 与全仓历史记录。
