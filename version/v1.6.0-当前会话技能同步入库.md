# v1.6.0-当前会话技能同步入库

## 背景与目标

当前 Codex 会话可见的技能来源包含本机 `~/.codex/skills/`、系统技能 `.system/`、以及本机插件缓存中可扫描到的 Browser、Chrome、LaTeX、Figma、Hyperframes、Supabase、文档/表格/演示等技能。

本项目约定 `skills-shared/` 是唯一技能来源，因此需要把当前会话可用但尚未写入本项目的技能补齐到 `skills-shared/`，让后续 Cursor / Codex / Claude Code 共用同一套技能资产。

## 需求范围

### 本次包含

- 扫描当前会话可见技能与 `skills-shared/` 已有技能的差异。
- 新增缺失的系统技能镜像：`imagegen`、`openai-docs`、`plugin-creator`、`skill-installer`。
- 新增缺失的本机技能：`hatch-pet`。
- 新增缺失的插件技能镜像：Browser、Chrome、LaTeX、Figma、Hyperframes、Supabase、Superpowers 扩展、Documents、Presentations、Spreadsheets。
- 保留已存在的同名技能，不覆盖当前项目已有版本。
- 更新 `skills-shared/README.md`，补充同步说明与索引入口。

### 本次不包含

- 不覆盖 `skills-shared/` 中已存在的同名技能。
- 不处理当前工作区已有的未提交删除或修改记录。
- 不安装或启用插件，只把可见技能文件沉淀到项目。
- 不改动业务项目源码。

## 实施步骤

1. 读取当前项目技能目录与本机会话技能来源。
2. 对比缺失技能，形成只新增不覆盖的同步清单。
3. 创建本版本文档。
4. 复制缺失技能目录及其 `references/`、`scripts/`、`assets/` 等资源。
5. 更新 `skills-shared/README.md` 的维护说明。
6. 验证新增目录均包含 `SKILL.md`，并统计同步结果。

## 风险与回滚

- 风险：插件缓存技能来自本机缓存，后续插件升级后内容可能变化。
  - 处理：本次作为当前可见版本快照入库，后续升级再按新版本单独同步。
- 风险：同名技能存在多个来源，直接覆盖会丢失本项目定制内容。
  - 处理：本次保留项目已有同名目录，只新增缺失目录。
- 风险：部分技能依赖 Codex 插件工具或系统工具，复制后不代表独立可运行。
  - 处理：README 中标注这些目录属于镜像资产，使用时仍需对应运行环境支持。
- 回滚：删除本次新增的缺失技能目录，恢复 `skills-shared/README.md` 的新增段落，并删除本版本文档。

## 验收标准

- `version/v1.6.0-当前会话技能同步入库.md` 存在。
- 当前会话可见且项目原先缺失的技能已新增到 `skills-shared/`。
- 已存在的同名技能未被覆盖。
- `skills-shared/README.md` 包含系统/插件技能镜像说明。
- 能通过文件扫描确认新增目录均包含 `SKILL.md`。

## 复盘沉淀

- 技能同步不能只按目录名判断，因为存在 `skills-shared/superpowers` 这类目录名与 frontmatter `name:` 不一致的情况；后续同步统一按 `name:` 判重更稳。
- 外部插件技能应作为快照资产入库，README 需要说明其运行仍依赖对应 Codex 插件或系统工具，避免误以为复制目录后即可独立执行所有能力。
- 已有同名技能优先保留项目版本，不覆盖本项目沉淀过的定制内容；需要对比升级时再单独开版本处理。
