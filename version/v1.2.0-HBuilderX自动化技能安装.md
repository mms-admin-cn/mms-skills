# v1.2.0-HBuilderX自动化技能安装

## 背景与目标

当前个人 Codex 技能库中已有 `hbuilderx-automation`，它沉淀了 HBuilderX CLI 自动化、Uni-App X 编译验证、设备运行、日志判断、截图与常见 UTS 排障模式。

本仓库采用 `skills-shared/` 作为唯一技能来源，需要把该技能安装到共享技能库，并与已新增的 `mms-unix-hbuilderx-runbook` 建立调用关联。
