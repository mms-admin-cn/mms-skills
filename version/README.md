# version 目录规范

本目录存放“每个新功能”的版本需求文档。

## 命名规范
- `v主版本.次版本.修订版本-功能说明.md`
- 示例：
  - `v1.0.0-用户登录重构.md`
  - `v1.1.0-订单列表筛选增强.md`
  - `v1.1.1-订单导出修复.md`

## 递增规则
- 大变更：主版本 +1（如 `v1.x.x -> v2.0.0`）
- 新特性：次版本 +1（如 `v1.1.0 -> v1.2.0`）
- 小修复：修订版本 +1（如 `v1.2.0 -> v1.2.1`）

## 强制流程
1. 先分析需求
2. 再创建版本文档
3. 再开始开发
4. 开发过程同步进度
5. 完成后复盘沉淀
