# v1.11.0-首页字体排版优化

## 背景与目标

官网首页在中文内容场景下字号偏大，标题换成两行后行距过紧，部分区块标题与正文上下距离不协调。此次优化目标是保留首页展示质感，同时把字体尺度收回到中文官网与工具型说明页更稳定的阅读密度。

## 需求范围

- 优化首页首屏标题字号、行高和上下间距。
- 优化首页说明文字、区块标题、卡片标题、按钮、标签的字号层级。
- 调整移动端断点，避免中文长句换行后显得拥挤。
- 保持现有首页结构、内容、动效和交互不变。

## 实施步骤

1. 梳理 `index.html` 现有字体尺度，定位过大的 `clamp()`、偏紧的 `line-height` 和过密的间距。
2. 将首页主标题从展示型大字调整为中文官网稳定尺度，并提高两行标题行高。
3. 收敛区块标题、卡片标题、正文、按钮、状态标签的字号和字重。
4. 补充移动端专用排版规则，确保两行标题和正文不贴在一起。
5. 启动本地页面并通过浏览器检查桌面与移动视口。

## 风险与回滚

- 风险：字号收敛后首屏视觉冲击力下降。
- 应对：保留渐变标题、动效背景、状态面板和按钮视觉层级，只降低文字夸张程度。
- 回滚：恢复 `index.html` 中本次字体、行高、间距相关 CSS 修改即可。

## 验收标准

- 首页主标题在桌面与移动端两行显示时行距自然，不上下挤压。
- 中文正文、按钮、卡片标题不再显得偏大或笨重。
- 各区块标题与说明文字之间留白稳定，页面整体更协调。
- 浏览器检查无明显文字重叠、裁切或异常换行。

## 复盘沉淀

- 中文官网与工具型页面应优先按 `14px` 正文基准和 `18px - 22px` 常规标题层级设计，只有真正营销首屏才使用大标题。
- `h1` 使用 `clamp()` 时不能只看桌面气势，还要确认中文两行时的 `line-height`，建议不低于 `1.12`。
- 中文长句容易形成整行块面，字号、字重、行高、容器宽度要一起调，不能只缩字号。
