# v1.8.0-README特色技能清单

## 背景与目标

当前 README 已经说明项目版本、安装和三端接入方式，但对 `skills-shared/` 中哪些技能最有价值、分别适合什么场景、如何触发使用，还缺少直观入口。

本次目标是在 README 中新增 20 款特色且实用的技能介绍，让新接入的软件、Agent 或开发者不需要翻完整目录，也能快速知道优先使用哪些技能。

## 需求范围

### 本次包含

- 版本递增到 `v1.8.0`。
- 更新 `PROJECT_VERSION` 与 `mms-skills.json`。
- 在根 `README.md` 中新增 20 款特色技能清单。
- 每款技能说明适用场景、特色能力和使用方法。

### 本次不包含

- 不修改具体技能正文。
- 不新增新技能。
- 不改变三端安装方式。

## 实施步骤

1. 从当前技能库中选择 20 款最具代表性、最实用的技能。
2. 更新项目版本标识到 `v1.8.0`。
3. 在 README 的使用说明后新增“20 款特色实用技能”表格。
4. 验证 README 中版本号、技能数量和清单内容一致。

## 风险与回滚

- 风险：技能清单过长影响 README 首屏阅读。
  - 处理：放在安装和基础使用之后，使用表格压缩表达。
- 风险：介绍过细导致后续维护成本高。
  - 处理：只写稳定场景、特色能力和触发方式，不复制技能正文。
- 回滚：恢复 `PROJECT_VERSION`、`mms-skills.json` 和 `README.md`，删除本版本文档。

## 验收标准

- README 顶部版本显示 `v1.8.0`。
- README 中存在 20 款特色技能介绍。
- 每款技能都有适用场景和使用方法。
- `PROJECT_VERSION` 与 `mms-skills.json` 版本一致。

## 验证结果

- `PROJECT_VERSION` 已更新为 `v1.8.0`，并通过版本一致性检查。
- `mms-skills.json` 已更新为 `version: v1.8.0`，Node 读取验证通过。
- 根 `README.md` 顶部版本徽标、快速识别、自检命令均已同步为 `v1.8.0`。
- `README.en.md` 的版本与自检命令已同步为 `v1.8.0`。
- 已验证 README “20 款特色实用技能”表格包含 `20` 条技能记录。

## 复盘沉淀

- README 中的技能介绍应优先服务“快速选技能”，不要复制完整技能正文；保持“特色能力、适用场景、使用方法”三段即可。
- 技能清单适合放在安装和基础使用之后，既不干扰新用户安装，也能让已接入者快速查找入口。
- 每次 README 内容增强仍需要同步 `PROJECT_VERSION`、`mms-skills.json` 和英文快速入口，避免多处版本漂移。
