# v1.1.0-mms-unix文档技能化

## 背景与目标

将 `mms-cashier/mms-unix/docs/` 下两份稳定文档沉淀为共享技能，避免后续在离线同步、接口契约、HBuilderX 运行排障时重复翻文档。

目标：
- 新增 `mms-unix-sync-api-contract` 技能，覆盖 MMS Admin 同步接口与离线补传契约。
- 新增 `mms-unix-hbuilderx-runbook` 技能，覆盖 Uni-App X + HBuilderX 的 H5、Android、UTS、横屏与 UCSS 排障流程。
- 在共享技能索引中补充触发词和关联关系，让 Agent 能按任务语义选择对应技能。

## 需求范围

### 本次包含

- 新增两个技能目录，每个目录至少包含 `SKILL.md`。
- 技能内容来自以下源文档：
  - `/Users/shanpengnian/MyWork/mms-cashier/mms-unix/docs/sync-api-contract.md`
  - `/Users/shanpengnian/MyWork/mms-cashier/mms-unix/docs/uni-app-x-hbuilderx-runbook.md`
- 更新 `skills-shared/README.md`，补充技能清单与调用关联。
- 在 `mms-dev-workflow` 中补充“文档技能化”的复盘模式。

### 本次不包含

- 不修改 `mms-cashier/mms-unix` 业务源码。
- 不调整同步接口实现。
- 不执行 HBuilderX 编译或 Android 运行验证。

## 实施步骤

1. 读取共享技能规范与两份源文档。
2. 创建 `version/v1.1.0-mms-unix文档技能化.md`。
3. 新增 `skills-shared/mms-unix-sync-api-contract/SKILL.md`。
4. 新增 `skills-shared/mms-unix-hbuilderx-runbook/SKILL.md`。
5. 更新共享技能索引，建立触发词与技能关联。
6. 复盘本次沉淀模式，补充到工作流技能中。

## 风险与回滚

- 风险：技能描述触发词过窄，后续无法自动命中。
  - 处理：描述中覆盖“同步接口、离线同步、syncQueue、MMS Admin、HBuilderX、UTS、Android、H5、横屏”等关键语义。
- 风险：源文档后续变化而技能未更新。
  - 处理：技能中保留源文档路径，后续维护时先对照源文档刷新。
- 回滚：删除两个新增技能目录，并恢复 `skills-shared/README.md` 与 `mms-dev-workflow/SKILL.md` 的本次新增段落。

## 验收标准

- `skills-shared/mms-unix-sync-api-contract/SKILL.md` 存在，且包含同步接口、队列类型、幂等规则、接口清单。
- `skills-shared/mms-unix-hbuilderx-runbook/SKILL.md` 存在，且包含固定命令、成功标记、排障顺序、横屏与 UTS 规则。
- `skills-shared/README.md` 包含两个技能的调用关联。
- `mms-dev-workflow/SKILL.md` 包含文档技能化复盘模式。
