# v1.12.5-技能库防御性重构与安装体验优化

## 背景与目标

v1.12.3 和 v1.12.4 虽然增加了问候豁免和任务分级，但修复只停留在"加豁免规则"层面，没有触及两个核心矛盾：

1. `superpowers/SKILL.md` 的 `<EXTREMELY-IMPORTANT>` 块用"1% 可能就必须用技能"直接否定了分级系统
2. **Codex 插件缓存中的 `using-superpowers/SKILL.md` 仍是旧版**，每次会话启动时先于 AGENTS.md 加载

同时，项目安装流程靠手动复制 + 硬编码路径，对其他人极不友好。

目标：
- 防御性重构：从"默认加载技能"翻转为"默认不加载"
- 修复插件缓存的双重来源问题
- 提供一键安装脚本，降低使用门槛

## 核心改动

### 1. 防御性重构

| 文件 | 改动 |
|------|------|
| `AGENTS.md` | 删掉"标准执行顺序"，新增"默认不加载技能"规则，新增插件优先级声明 |
| `skills-shared/superpowers/SKILL.md` | `<EXTREMELY-IMPORTANT>` 翻转，Red Flags 表重写，新增 PHATIC-EXEMPTION、TASK-TIERING |
| `skills-shared/mms-dev-workflow/SKILL.md` | "强制规范"→"执行规范"，新增退出条件 |
| `CLAUDE.md` `.cursorrules` `.cursor/rules/00-project-bootstrap.mdc` | 同步 AGENTS.md |

### 2. Codex 插件缓存同步修复（关键）
- 修复了 `~/.codex/plugins/cache/.../using-superpowers/SKILL.md`
- 将 skills-shared 修复版完整同步到插件缓存
- description 从 "requiring Skill tool invocation before ANY response" 改为防御性表述

### 3. 安装体验优化

| 新增/改动 | 说明 |
|-----------|------|
| `install.sh` | 一键安装脚本，自动检测路径、替换硬编码地址、支持 `--codex/--cursor/--claude/--all/--target/--shell` |
| `README.md` 重写 | 快速安装置顶、技能索引精简为表格、修复版本号（v1.10.0→v1.12.5）和技能数（84→83）、新增常见问题 |

### 4. 发现的技能冲突

83 个技能中有 34 个（41%）与 Codex 内置/插件重复：Superpowers 14 个、Figma 8 个、Hyperframes 5 个、系统 5 个、Supabase 2 个。
优先级声明：AGENTS.md > 插件描述。

## 设计原则

| 旧 | 新 |
|----|----|
| 默认加载技能，豁免不加载 | 默认不加载，明确需要才加载 |
| 不确定时 → 用技能 | 不确定时 → 跳过技能 |
| 手动复制 + 硬编码路径 | `install.sh` 一键安装 + 自动路径替换 |
| README 冗长 200+ 行 | 简洁，快速安装在最前面 |

- `skills-shared/mms-dev-workflow/SKILL.md`：软化 + 退出条件

- 发送"帮我加登录页面" → 只加载 mms-dev-workflow，不加载其他技能
