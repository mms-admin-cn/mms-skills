# v1.12.3-问候语免技能加载优化

## 背景与目标

Codex 安装技能库后，发送"在吗"等纯问候消息时，`superpowers:using-superpowers` 技能强制拦截，要求 Agent 在任何回复前先检查/加载技能。由于 Codex 没有原生 `Skill` 工具，Agent 退化为反复手动读取技能文件，造成约 2 分钟的卡顿和重复输出。

目标：让纯问候/状态确认类消息直接秒回，不再触发技能加载链。

## 需求范围

### 本次包含
- `superpowers/SKILL.md` 增加 `<PHATIC-EXEMPTION>` 豁免条款
- `AGENTS.md` / `CLAUDE.md` / `.cursorrules` / `.cursor/rules/00-project-bootstrap.mdc` 增加问候豁免指引

### 本次不包含
- 不修改技能触发的核心逻辑（实质性请求仍正常触发）
- 不删除或弱化任何技能

## 实施步骤

1. superpowers/SKILL.md：在 `</SUBAGENT-STOP>` 和 `<EXTREMELY-IMPORTANT>` 之间插入 `<PHATIC-EXEMPTION>` 块，明确定义纯问候消息直接回复、不加载技能。
2. Red Flags 表新增 "问候语不需要检查技能" 条目。
3. AGENTS.md 核心规范新增第 2 条：纯问候直接回复。
4. CLAUDE.md 同步更新。
5. .cursorrules 同步更新。
6. .cursor/rules/00-project-bootstrap.mdc 同步更新。

## 风险与回滚

- 风险：豁免范围过宽，导致某些应触发技能的消息被误判为问候。
  - 处理：豁免块明确列举了纯问候示例，并规定"不确定时按实质性消息处理"。
- 回滚：revert 本次 commit 即可。

## 验收标准

- 发送"在吗"不再触发技能加载，直接秒回
- 发送"帮我修复这个 bug"仍正常触发技能链
- 所有入口文件（AGENTS/CLAUDE/cursorrules/bootstrap）规则一致
