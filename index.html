三端接入，只复制入口文件

目标项目不用复制全部技能正文，只接入对应入口文件，入口会引导 Agent 回到共享技能库读取 `SKILL.md`。

Codex

在目标项目根目录复制 `AGENTS.md`。

export MMS_SKILLS_HOME="/Volumes/SXPCWLKJ/MyWork/mms-skills"
cp -f "$MMS_SKILLS_HOME/AGENTS.md" "AGENTS.md"

Cursor

复制 Cursor rules 与兼容入口。

mkdir -p .cursor/rules
cp -f "$MMS_SKILLS_HOME/.cursor/rules/00-project-bootstrap.mdc" ".cursor/rules/00-project-bootstrap.mdc"
cp -f "$MMS_SKILLS_HOME/.cursorrules" ".cursorrules"

Claude Code

复制 `CLAUDE.md` 即可进入统一工作流。

export MMS_SKILLS_HOME="/Volumes/SXPCWLKJ/MyWork/mms-skills"
cp -f "$MMS_SKILLS_HOME/CLAUDE.md" "CLAUDE.md"

从一句需求到可复盘交付

每次工作都留下可追溯的版本文档，长会话也能靠文档恢复，不依赖对话历史硬撑。

01

匹配技能

先定位主技能，再读取关联技能。复杂任务先走 `mms-dev-workflow`。

02

创建版本文档

新功能先写 `version/vX.Y.Z-功能说明.md`，边界、风险、验收都写清楚。

03

开发与验证

按场景调用插件、UI、API、HBuilderX、Playwright 等技能，形成交付闭环。

04

复盘沉淀

把可复用模式写回技能库，让下一次 Agent 更快进入状态。

把技能库变成团队的第二大脑

从插件开发到页面美化，从服务部署到浏览器回归，所有经验都沉淀成能被 Agent 反复调用的技能。
